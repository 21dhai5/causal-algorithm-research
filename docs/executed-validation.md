# v1 实际执行记录

日期：2026-11-12。所有数据均为本机生成的合成观测；没有真实业务样本、现实因果效应验证或后台训练。以下为探索性实验，不是预注册确认性研究。

## 主实验

执行：

```powershell
python -B experiments/run_synthetic.py --seed 20261112 --samples 1200 --replications 100 --bootstrap-draws 400 --output artifacts/synthetic-v1.json
```

Python 3.12.10、NumPy 2.4.6。种子为 20261112–20261211，每次 1200 个原点；训练 `[0,720)`、校准 `[720,960)`、测试 `[960,1200)`。块长 6，条件块自助重复 400 次，已知合成一步效应为 1.5。完整结果见 [synthetic-v1.json](../artifacts/synthetic-v1.json)。

- 未调整组间差：100 次均可计算，偏差 0.65213、RMSE 0.70404；这是关联量，不具有自动因果解释。
- 调整后 g-computation：97/100 次通过共同支持门槛，偏差 0.00193、RMSE 0.08077。
- AIPW：97/100 次通过支持门槛，偏差 0.01220、RMSE 0.15990；95% 名义近似条件区间覆盖 90/97，即 92.78%。
- 3 次拒绝没有从报告中删除；应检查逐种子的原因。上述因果汇总以被接受的重复为分母，不代表所有运行的无条件表现。
- 动作已知的一步更新预测：100 次运行的 RMSE 平均为 0.99560；同期持久性基线平均为 1.84739。模型名义 90% 预测区间的平均经验覆盖为 91.10%。这些是逐运行指标的算术平均，不是对真实环境的效力推断。
- 全部 17 项内置来源、时间、幂等、修订与缺臂支持负对照通过。

区间只重采样留出 AIPW 分数，固定训练的干扰模型，未包含训练拟合不确定性。覆盖率不是有限样本保证。90/97 的覆盖比例还存在 Monte Carlo 不确定性；Wilson 近似区间约为 85.8%–96.5%，且只描述已接受重复中的覆盖比例。

## 敏感性与消融

执行 `python -B experiments/run_sensitivity.py`，完整结果见 [sensitivity-v1.json](../artifacts/sensitivity-v1.json)。

- 同一前 20 个合成种子的训练窗口回归消融：完整调整 RMSE 0.08808；省略混杂 x 的回归相对真值 RMSE 0.69915；增加独立噪声特征后 RMSE 0.08982。遗漏变量回归属于未识别的对照，不应解释为因果效应。
- 相同 20 个种子、块长分别为 3、6、12：三个配置均 20/20 有效，AIPW RMSE 均为 0.12968，区间均覆盖 19/20。点估计不随块长改变；相同的覆盖计数不表示区间相同，也不能证明任意依赖下稳健。
- 额外固定延迟 5 步、600 样本、10 个种子：校准排除了测试开始前尚未到达的 5 个标签；10/10 AIPW 有效，RMSE 0.14069，区间覆盖 10/10。该小样本结果不是覆盖保证。
- 延迟场景假定当前 x、y 可由另一条状态观测路径及时测得，只延迟标签入口；未测试结果依赖删失或当前状态缺失。
- 漂移演示只使用一个配对种子，测试期把结果转移均值增加 3；告警是残差尾部诊断，不是因果图变化的证明。

## 独立审查与修复

独立审查完整阅读首版 Python 实现并运行针对性内存探针，发现并修复：

1. 数组下标被误作真实时钟：审计示例和首次告警改为读取记录的 `origin_time`。
2. 效应辅助接口未拒绝训练/测试重叠：现检查严格时间顺序、来源一致和训练标签可用性；真实数据识别尚未实现，辅助估计器对此明确拒绝。
3. 延迟最终指标语义不清：报告现在带 `evaluation_as_of` 和 `ALL_TEST_LABELS_MATURED`，明确为所有固定测试标签成熟后的回顾性评分。

根集成后的内存复核通过：训练测试交叠拒绝、真实/合成来源不一致拒绝、原点整体平移 1000 后的时钟正确、延迟 7 步的校准只保留 73 行且首个测试预测不含当前结果。未保留临时测试脚手架。

账本修订可保留过去快照，但完整事件驱动评分修订与模型回放仍未实现。账本来源是调用方声明，不能认证真实来源。

- 离线 HTML 已嵌入本版实际主实验结果；通过隔离、无个人资料的无头浏览器检查，能显示 100 个种子、切换逐种子结果，390 像素宽页面无横向溢出，未出现脚本错误。已查看桌面及移动截图；临时截图不保留。
- 本项目是全新 Git 历史，不复用旧项目源码或历史。提交使用 GitHub noreply 地址，避免公开本机私人邮箱。
- 实现不读取真实数据，不发起网络请求，不执行外部命令或真实干预。HTML 本地文件仅经 JSON 解析，以 `textContent` 展示，策略禁止网络连接。
- CI 仅有只读仓库权限；官方动作固定到实际查验的提交，不使用 `pull_request_target` 或仓库密钥执行外部 PR 代码。
- OSV 查询 `numpy==2.4.6` 于本次执行返回无公告；这只是该查询时点的数据库结果，不是无漏洞证明。PyPI 元数据额外请求超时；依赖可获取性仍需由实际 CI 安装验证。
- 本地 CLI 默认独占创建结果，显式覆盖时拒绝符号链接。面对恶意共享目录中的并发换链仍有边界，因此不应在其他人可写的目录使用覆盖模式。

尚未完成隐藏新混杂、结构性支持空洞、结果依赖延迟、完整纠错回放、全流程推断和真实长期策略验证。这些缺口不会因为当前合成指标良好而消失。
