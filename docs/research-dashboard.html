01

项目定义与目标边界

研究四类问题，分别输出结论；预测分数不能替代识别依据。

  1. 关联样本中的变量如何共同变化？
    相关、回归和条件独立关系。
  2. 预测给定当前信息，下一步会怎样？
    明确自然动作或已观测动作模式。
  3. 因果把动作设为另一值，结果如何改变？
    先指定人群、窗口与识别假设。
  4. 决策考虑成本和约束，应采取什么动作？
    另需日志策略、支持与风险依据。
v1 目标：形成可用性快照、按时间预测与反馈评分、固定目标效应估计及来源审计。无动作或无识别依据时，退回预测研究；允许输出明确失败状态。
02

关键假设与信息缺口

工作假设 初始建模约定

  • 离散时间，单条时间序列或多单位面板；单位内允许时间依赖。
  • 动作前形成状态 Ct；只纳入当时已到达的结果、协变量和滞后。
  • At ∈ {0, 1}，目标为 Yt+1；标签可能延迟、缺失或被纠正。
  • 压缩历史的有限特征不自动包含充分混杂信息。

待验证 真实场景启动条件

  • 单位、时间粒度、动作定义及前后次序。
  • 结果量纲、观察窗口、延迟和纠错机制。
  • 目标人群、历史动作策略、可测混杂及干扰。
  • 动作成本、禁止动作、误差容限与决策权限。

每条记录至少登记 unit_id、event_time、available_at、record_id、版本与来源。诊断通过不能证明无未测混杂、一致性或排除限制成立。

03

总体架构与数据流

预测闭环随合法反馈更新；因果主分析固定目标、训练拟合与评估窗口。两者共享版本和来源审计。

  1. 记录入库
  2. 可用性快照
  3. 历史特征
  4. 一步预测
  5. 冻结账本
  6. 新标签评分
  7. 受控更新
  1. 领域图与候选图
  2. 识别或拒绝
  3. 固定窗口估计
  4. 支持及不确定性审计
来源边界：四种记录不能相互冒用
记录来源允许的用途
real_observation真实观测；只有这一类可成为真实业务标签。
synthetic_observation仅在独立合成实验命名空间内作为合成标签。
model_prediction预测账本与评分对象；始终不是已观测标签。
counterfactual_simulation反事实模拟；始终不是已观测标签。

纠错追加版本，保留旧快照与旧评分。相同版本重放不重复训练；来源不明时拒收。固定宽限期后仍无标签，报告缺失或右删失比例。

04

数学模型与因果识别

先锁定时间，再讨论调整

事件时钟 · event_time
事情实际发生的时间；合法事件窗口不晚于 t。
可用时钟 · available_at
系统能取得该记录版本的时间；不能事后回填。
预测时钟 · dt
发出预测的时刻；此时冻结信息集及特征版本。
Ht = σ{在 dt 前可用、事件时间 ≤ t 的合法记录版本}
Xt = φ(Ht)
未到达的 Yt 保留缺失状态。Ht 是可用历史，Xt 是实际使用的有限特征；充分调整需额外论据。
状态模型：潜在状态不等于充分混杂集
St+1 = fS(St, At, USt+1)
Ct = gC(St, UCt)
Yt+1 = gY(St+1, UYt+1)
At = fA(Ht, UAt)

函数形式、外生噪声独立性、缺失与测量机制均需声明；神经网络隐状态也不自动解决识别。

三种均值，三种问题

问题定义解释边界
自然动作预测E[Yt+1 | Ht]动作尚未发生；依赖自然动作分布。
观测动作预测E[Yt+1 | Ht, At = a]动作已发生且被观测；不自动具有因果含义。
干预均值E[Yt+1(a) | Ht]对应 do(At = a)；需要一致的干预语义及识别条件。

固定目标与后门路径

τW = EH ∼ P*W[Yt+1(1) − Yt+1(0)]
μa(x) = E[Yt+1 | At = a, Xt = x]
τW = EP*W[μ1(X) − μ0(X)] （仅在识别条件成立时）
  1. 一致性与干扰：动作版本明确；单位间无干扰，或已将干扰纳入设计。
  2. 条件交换性：(Y(0), Y(1)) ⟂ A | X；X 来自动作前，阻断相关后门，不误调中介或碰撞点。
  3. 正值性：目标支持域内两种动作均有正概率；稳定估计还要求概率远离边界。
  4. 目标对应：选择、测量、标签到达及跨时间迁移机制允许识别目标分布。
AIPW：双重稳健的适用范围
τ̂ = mean[ μ̂₁(X) − μ̂₀(X)
          + A · (Y − μ̂₁(X)) / ê(X)
          − (1 − A) · (Y − μ̂₀(X)) / (1 − ê(X)) ]

在识别、支持及适当依赖条件下，倾向模型一致，或两臂结果回归一致，可使估计器一致。根号样本量近似与有效区间还需更强正则及依赖条件。

双重稳健不保护未测混杂、错误目标或无支持。随机 K 折不能直接用于时间序列；采用先训练、后评估，并论证依赖控制。倾向截断不能恢复不存在的支持。

一步 ATE 不等于长期策略收益。既往动作影响未来混杂时，纵向扩展需顺序交换性、策略相关正值性及 g 方法等专门设计。识别不足时优先补测、随机试验或明确报告不可识别。
05

算法选择与方法取舍

研究任务v1 主线选择依据与升级条件
一步预测持久性、线性 AR / ARX先建立透明基线；未发生的动作不得作为实际输入。有明确周期才增设季节性基线。
效应估计未调整差、g-computation、AIPW比较混杂偏移与调整效果；未调整差仅作有偏基线，不验证识别。
倾向与结果模型二值概率模型、线性 OLS检查支持、校准与拟合。非线性和样本量允许时再引入更复杂模型。
预测更新滚动 / 扩展窗口可重放、先评分后更新；因果主分析仍冻结。
图与区间扩展条件触发的后续研究PCMCI 提出候选图；自适应保形方法需核对保证及漂移条件。

方法取舍参照来源 R1–R5；目前多数只核对摘要，不能据此为本项目声明完整理论或复现结论。详见 实际查阅范围。

深度状态模型、大模型和强化学习增加数据与验证成本；复杂度升级需由固定测试协议下的增益、误差诊断及维护成本共同支持。离线决策评价要先取得可信日志动作概率与充分支持。

06

预测、反馈与更新闭环

每条标签先评价其对应的旧预测，再进入合格反馈队列。

固定协议：目标、窗口、特征、来源、时间切分与验收指标
只在较早训练窗口拟合模型；冻结因果目标和评估定义

对每个发出时刻 d_t：
  接收当时已到达的记录，核对来源、版本与幂等键
  对合法新标签或纠错标签：
    匹配旧预测与原始冻结快照
    先评分并记录标签版本；同一版本不重复处理
  检查残差、缺失、动作分布与支持漂移
  按登记规则使用已评分反馈更新预测模型
  按 available_at 形成快照，保存当前特征与模型版本
  发出自然预测，或动作确已观测后的条件预测
  若请求效应：先检查识别、支持与标签成熟状态
    条件不足 → 返回拒绝原因
    条件满足 → 在冻结窗口估计，不写回真实标签
  审计观测 → 快照 → 预测 → 评分 → 更新

延迟标签不能用于重生成更好的旧预测。纠错保留历史并触发版本化重算或回放。漂移触发监测、审查与回退，候选动作策略保持冻结。

07

实验设计与验收门槛

模拟 可控机制，已知一步效应

xt = 0.6xt−1 + εxt
et = clip(sigmoid(0.8xt − 0.2Yt), 0.1, 0.9)
At ∼ Bernoulli(et)
Yt+1 = 0.5Yt + 0.8xt + τAt + εyt+1，τ = 1.5
独立标准高斯创新、初值为零、无预热，随机流与依赖版本写入报告。截断后的分配机制并非精确的普通逻辑回归。已知效应是合成定义，不是真实数据发现。
  1. 训练：拟合变换与模型
  2. 校准：固定区间协议
  3. 测试：按时间评价

禁止随机切分时间序列或用测试集挑模型。对冻结与更新预测模型使用同一可用信息与种子配对比较；因果主分析保留固定训练拟合和测试目标。

六组必要压力实验

  1. 混杂：完整调整、遗漏 xt、未观测共同原因。
  2. 重叠：极端倾向及结构性单动作区域，检验拒绝行为。
  3. 延迟：固定、随机及依赖结果的到达；重复记录与标签纠错。
  4. 漂移：协变量、噪声或效应变化，另设目标窗口。
  5. 阴性诊断：独立噪声、残差时间结构；通过不证明无混杂。
  6. 泄漏：未来标签、未到达动作及模拟反馈必须拒绝或隔离。
评价层必须报告
预测MAE、RMSE、配对差异、分时段误差、可评分率；有区间时报告覆盖与宽度。
因果模拟 ATE 偏差、RMSE、区间覆盖与宽度；拒绝率、权重尾部、有效样本量和两臂数量。
依赖与审计残差自相关、单位数、轨迹长度、间隔；泄漏、来源违规、重复更新及回放一致性。

硬门槛 · 实现后逐项核验

时间 / 来源违规为 0；预测与模拟写入真实标签数为 0；重复不训练；纠错留版本；先评分后更新；无支持拒绝；固定配置可重放。未实现项只能写待完成。

待验证 确认性门槛

独立试点后锁定至少 100 个种子、样本量、区间及指标阈值。偏差 ≤ 0.15、RMSE ≤ 0.30、95% 区间覆盖 90%–99% 仅是 τ = 1.5 时的设计候选。

少量种子只能提供冒烟证据。预测区间与效应置信区间回答不同问题；时间依赖需有依据的 HAC、块自助或单位聚类。长记忆、突变及块长选择可能使区间失效。

08
最小原型与实施阶段

      
按证据退出阶段；实际运行和实现范围以原型报告为准。本页不预填实现完成状态或性能结果。

      
  1. 阶段 0
    锁定问题和协议
    交付研究计划、来源、DGP、时间切分、估计量与失败状态；可检查所有时钟及数据边界。
  2. 阶段 1
    可运行的合成最小原型
    NumPy 线性机制、二值动作、时间切分、预测基线、调整估计、AIPW 与简单预序更新；逐项列明覆盖和缺口。
  3. 阶段 2
    压力与确认性实验
    补齐延迟、纠错、重放、支持与漂移；独立试点后锁定至少 100 种子协议，完整报告失败。
  4. 阶段 3
    真实场景只读验证
    补齐数据字典、领域图与识别依据；做可用性回测、重叠及敏感性分析，必要时转向补数或试验。
  5. 阶段 4
    另立决策研究
    目标与日志策略、支持、成本及权限明确后，再设计顺序离线评价或受控试验。

    


    

      
09
主要风险与下一步行动

      
风险下一步
识别失效核对领域顺序、混杂、干扰与动作定义；必要时补测、试验或部分识别。
时间 / 选择偏差固定可用性快照与标签成熟协议；不直接删除未到达标签。
支持 / 推断不足先查目标与支持，明确拒绝；独立重复并做依赖与块长敏感性分析。
自证反馈循环隔离四类来源，冻结确认性协议，先评分后更新；漂移触发审查。
解释越界为输出附上问题类型、目标、假设及支持范围；候选图、预测、平均效应与决策分别解释。

      
立即行动顺序
运行并核验合成原型 → 补齐压力实验 → 锁定真实场景与信息缺口 → 独立试点后预注册确认性协议。全文核验及依赖理论不足时，区间维持探索性说明。
